# Datos de haz sintéticos

Curvas generadas con el propio motor a partir de un modelo "verdad" conocido
(espectro, cuernos, fuente extrafocal y contaminación electrónica distintos de
los del modelo genérico), con ruido del 0.2%. Sirven para probar el comisionado:

    python -m calcindep comisionar examples/gbd_sintetico/comisionado.json

No son datos de ninguna máquina real.
